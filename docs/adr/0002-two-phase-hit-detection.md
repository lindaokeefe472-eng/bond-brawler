# ADR-0002：命中判定分两段，领域层是唯一权威

- 状态：已接受
- 日期：2026-10-28

## 背景

横版清版游戏的手感高度依赖「判定准不准」。常见的两种做法都有问题：

1. **纯物理判定**（`Area3D` 重叠就算命中）：物理帧率 60Hz 但渲染帧率不定，
   高速位移时会穿透（tunneling），同一招的判定框在不同机器上结果不同。
2. **纯逻辑判定**（完全不用物理）：要自己实现空间划分，敌人一多就慢。

## 决定

两段式：

| 阶段 | 实现 | 职责 |
|---|---|---|
| 宽相 | `Area3D`（`HitboxAdapter` / `HurtboxAdapter`） | 只回答「谁可能在范围内」 |
| 窄相 | 领域层 `PlaneMath.in_cone` + 纵深对齐 + 帧数据 | 回答「到底打没打中、打多少」 |

伤害数值**只**由 `CombatDamageCalculator` 产生。物理层永远不写血量。

## 后果

- 宽相漏判（物理抖动）只会导致「少打一次」，不会导致「伤害算错」
- 判定逻辑可以单测：给定两个平面坐标 + 朝向 + 帧数据，结果唯一确定
- 联机时只需同步平面坐标与状态机，不需要同步物理

## 约束

`HitboxAdapter` 不得直接扣血；`ActorView` 收到重叠后必须回传给 `BattleSession` 走窄相。

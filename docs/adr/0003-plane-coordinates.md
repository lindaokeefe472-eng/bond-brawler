# ADR-0003：领域层使用平面坐标，高度是独立标量

- 状态：已接受
- 日期：2026-10-28

## 背景

2.5D 横版动作有两种坐标建模方式：

1. 直接用 `Vector3`，锁死 Z 轴
2. 用 `Vector2` 表示地面平面，高度单独一个标量

## 决定

领域层用 `Vector2(x, lane)`：

- `x` → 世界 X（横轴）
- `lane` → 世界 Z（纵深），范围 `[LANE_MIN, LANE_MAX]`
- 高度 `height` 是独立 `float`，不进入平面坐标

映射由 `PlaneMath.to_world(p, height)` 在表现层完成。

## 理由

- 纵深判定（清版游戏的核心）变成一行 `abs(a.y - b.y) <= tolerance`，
  如果混在 `Vector3` 里，每次都要记得只比较 x/z，容易写错
- 空中与地面共用同一套平面几何：跳跃只改 `height`，不改命中判定
- 领域层不需要知道「角色站在多高」，简化 AI 与寻路

## 后果

- 表现层必须做一次坐标映射（成本极低）
- 需要跳跃攻击时，用 `height` 差做额外条件，而不是改坐标模型
